# L1 vs L2 正则化

- **惩罚项**：L1 = $\lambda \sum_i |w_i|$；L2 = $\lambda \sum_i w_i^2$
- **核心区别**：**L1 会让权重稀疏（很多 $w_i = 0$），L2 只会让权重变小但非零**
- **为什么 L1 稀疏？**
	- **梯度角度**：L1 梯度恒为 $\pm\lambda$（与 $w$ 无关），即使 $w$ 很小也往 0 推；L2 梯度 $2\lambda w$，$w$ 趋 0 时梯度也趋 0，只能无限逼近
	- **几何角度**：L1 约束区域是菱形（尖角在坐标轴上），等高线易切在尖角 → 对应维度 = 0；L2 是圆，切点几乎不在坐标轴上
	- **贝叶斯角度**：L1 ⟺ Laplace 先验（尖峰）；L2 ⟺ Gaussian 先验（平滑）
- **其他性质**：L1 对离群值更鲁棒，在 0 处不可微（次梯度/Proximal）；L2 处处可微，有闭式解
- **应用选择**：
	- 特征冗余多、需特征选择 → **L1**
	- 只想抗过拟合、训练稳定 → **L2**
	- 兼顾 → **Elastic Net**（$\lambda_1 \|w\|_1 + \lambda_2 \|w\|_2^2$）
	- 推荐系统：**FTRL** 本质是带 L1 的在线学习，训出稀疏 LR/FM，上线裁零权重省存储

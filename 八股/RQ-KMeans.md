# RQ-KMeans（残差量化 K-Means）

- **核心思想**：在**原始 embedding 空间**逐级做 K-Means 聚类，无神经网络参数
- **流程**：
	1. Level 0：对原始 embedding $x$（768d）跑 K-Means → 得 $c_0$，残差 $r_1 = x - e_{c_0}$
	2. Level 1：对残差 $r_1$（768d）跑 K-Means → 得 $c_1$，残差 $r_2 = r_1 - e_{c_1}$
	3. 重复至 Level $m-1$，最终 SID = $(c_0, c_1, \dots, c_{m-1})$
- **优点**：实现简单，无需训练神经网络，计算开销低
- **缺点**：
	- 在高维空间（768d）聚类，受**维度灾难**影响，聚类质量下降
	- 逐级**贪心优化**，无全局目标，无法保证量化后信息保留最优
	- 码本向量维度 = 原始维度，存储开销大
